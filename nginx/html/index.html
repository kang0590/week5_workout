WEEK 5 · CAPSTONE

글쓰기 도우미

누적 조회수 불러오는 중

프로젝트 소개

글쓰기 도우미는 사용자가 떠오른 생각을 정리하고 글의 목적에 맞게 내용을 구성하여 자신의 문장으로 완성할 수 있도록 돕는 웹 서비스입니다.

주요 기능

사용자가 자신의 생각을 자유롭게 입력하면 내용을 구조화하여 보여주고, 사용자가 직접 구조와 순서를 수정한 뒤 자신의 문장으로 글을 작성할 수 있도록 지원합니다.

사용 기술

HTML, CSS, JavaScript를 사용하여 웹 화면을 구성하고, Flask를 활용하여 API 기능을 구현합니다.

팀 소개

팀원들이 역할을 분담하여 웹 화면 설계, 기능 구현, 테스트 및 프로젝트 문서 작성을 진행합니다.

API 연결 확인

페이지를 열거나 새로고침하면 조회수가 증가합니다.
